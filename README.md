RMG Construtora – Website Institucional

Website institucional desenvolvido para a RMG Construtora, empresa que atua com terceirização de serviços, construção civil, reformas e melhorias de ambientes.

O projeto foi criado com foco em apresentar a empresa de forma clara, profissional e moderna, garantindo uma boa experiência para o usuário e um código organizado para fácil manutenção.

Sobre o Projeto

Esta aplicação frontend foi desenvolvida utilizando tecnologias modernas do ecossistema React.
O código foi estruturado de forma componentizada, com estilos organizados e reutilizáveis, facilitando futuras evoluções do projeto.

Durante o desenvolvimento, foram aplicadas boas práticas de organização, legibilidade e padronização, visando tanto o uso real do projeto quanto sua apresentação em portfólio.

Tecnologias Utilizadas

O projeto utiliza React com TypeScript, tendo o Vite como ferramenta de build e desenvolvimento.

A estilização é feita com Tailwind CSS, complementado por CSS externo modularizado para melhor organização dos estilos.

A interface conta com componentes do Radix UI, animações com Framer Motion e ícones modernos.
Formulários e validações são implementados com React Hook Form e Zod.

Principais Características

Design responsivo
Componentização e reutilização de estilos
Estilos centralizados em arquivos CSS externos
Código organizado e de fácil manutenção
Boa performance e experiência do usuário

Scripts

Para iniciar o projeto em ambiente de desenvolvimento:

- npm run dev

Para gerar a build de produção:

- npm run build

Para verificação de tipos:

- npm run typecheck

Para formatação do código:

- npm run format.fix

Status

Projeto concluído e utilizado como site institucional, com possibilidade de melhorias futuras.
